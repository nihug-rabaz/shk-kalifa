# מערכת תצוגה דינמית - מפקדת הרבנות הצבאית

פרויקט זה נוצר עבור **מפקדת הרבנות הצבאית** - מערכת תצוגה דינמית למסכי מידע דיגיטליים.

## תיאור הפרויקט

מערכת תצוגה מתקדמת המאפשרת הצגת מידע דינמי על מסכי טלוויזיה, כולל:
- זמני תפילה דינמיים
- עדכונים והתראות
- הלכה יומית
- אגרת רבצ"ר
- מידע על ימי ישיבה
- זמני שאטל
- ועוד...

## טכנולוגיות

- **Next.js 14** - Framework ל-React
- **React** - ספרייה לבניית ממשק משתמש
- **TypeScript** - תמיכה בטיפוסים
- **CSS** - עיצוב רספונסיבי

## תכונות עיקריות

### 1. שיוך לוחות
- יצירת מזהה לוח ייחודי
- שיוך לוח באמצעות QR Code
- בדיקה אוטומטית של סטטוס שיוך
- מעבר אוטומטי למסך תצוגה לאחר שיוך

### 2. תצוגה דינמית
- שני מסכי תצוגה עם מעבר אוטומטי
- עדכון אוטומטי של תוכן מהשרת
- תמיכה במצב offline עם שמירה לוקאלית
- מזג נתונים חכם - הוספת נתונים חדשים לנתונים קיימים

### 3. תוכן דינמי
- **זמני תפילה**: עדכון אוטומטי לפי מיקום ויום השבוע
- **עדכונים**: רוטציה אוטומטית של עדכונים עם זמני תצוגה מותאמים
- **הלכה יומית**: טעינה יומית של הלכות עם גלילה אוטומטית לטקסט ארוך
- **אגרת רבצ"ר**: הצגת מכתבים שבועיים
- **ימי ישיבה**: תמונות ועדכונים על ימי ישיבה
- **הידעת**: פינת מידע עם תמונות וטקסט

### 4. עמידות וזמינות
- שמירה אוטומטית של כל הנתונים ב-localStorage
- מעבר אוטומטי למצב offline בעת ניתוק חיבור
- בדיקה תקופתית של סטטוס שיוך הלוח
- חזרה אוטומטית למסך שיוך אם הלוח מנותק

## התקנה והרצה

### דרישות מוקדמות
- Node.js 18+ 
- npm או yarn

### התקנה
```bash
npm install
```

### הרצה בפיתוח
```bash
npm run dev
```

האתר יהיה זמין ב-`http://localhost:3000`

### בנייה לייצור
```bash
npm run build
npm start
```

## שימוש

### 1. שיוך לוח חדש
1. פתח את האתר
2. סרוק את ה-QR Code באמצעות אפליקציית הרבנות
3. המערכת תעבור אוטומטית למסך התצוגה

### 2. תצוגה
- המערכת מציגה שני מסכים עם מעבר אוטומטי
- התוכן מתעדכן אוטומטית מהשרת
- אם אין חיבור, התוכן נטען מהשמירה הלוקאלית

### 3. ניהול
- אם הלוח מנותק, המערכת תחזיר אוטומטית למסך השיוך
- כל הנתונים נשמרים אוטומטית ב-localStorage

## API Endpoints

### `/api/board-info`
- `GET`: קבלת מידע על לוח
- `POST`: עדכון מידע לוח

### `/api/claim`
- `POST`: שיוך לוח

### `/api/check-claim-status`
- `GET`: בדיקת סטטוס שיוך

### `/api/display/content`
- `GET`: קבלת תוכן תצוגה

### `/api/halacha/daily`
- `GET`: קבלת הלכה יומית

### `/api/zmanim`
- `POST`: חישוב זמני תפילה

## תכונות מתקדמות

### שמירה לוקאלית
- כל הנתונים נשמרים אוטומטית ב-localStorage
- מזג נתונים חכם - נתונים חדשים מתווספים לנתונים קיימים
- תמיכה במצב offline מלא

### בדיקת חיבור
- זיהוי אוטומטי של ניתוק חיבור
- מעבר אוטומטי למצב offline
- עדכון אוטומטי בעת חזרת החיבור

### רוטציה אוטומטית
- עדכונים מתחלפים אוטומטית לפי זמני תצוגה מוגדרים
- תמונות "ימי ישיבה" ו"הידעת" מתחלפות אוטומטית
- מעבר אוטומטי בין מסכי תצוגה
