# מערכת תצוגה דיגיטלית — לוחות מסך עם ניהול מרחוק

לוח מלא־מסך לטלוויזיות שרץ 24/7 עם מוזיקת רקע, מתעדכן מרחוק מהנייד, ממשיך לעבוד
גם ללא אינטרנט, ומאפשר לנהל **קבוצות מסכים** (למשל ״בניין A״) — כל הקבוצה מציגה
את אותו לוח.

מבוסס על העיצוב של מערכת השילוט של מפקדת הרבנות הצבאית, עם backend חדש
(Next.js + Neon Postgres), ממשק ניהול לנייד, שיוך QR, ומוזיקה.

## תכולה

- **`/display`** — הלוח שרץ בטלוויזיה. שני מסכי עיצוב מתחלפים, זמני תפילה (קבועים
  או יחסיים לזמני היום), עדכונים, אגרת, הלכה יומית, ומוזיקת רקע. עובד offline.
- **`/admin`** — ממשק ניהול נייד (RTL): התחברות, קבוצות, עריכת תוכן, מוזיקה, מסכים.
- **API** — תוכן/קבוצות/מסכים/מדיה, אימות מנהל, זמני תפילה והלכה (חישוב מקומי).
- **`kiosk/`** — סקריפטים ל־Windows: Chrome במסך מלא, הפעלה אוטומטית, ריפוי עצמי.

## התחלה מהירה

```bash
npm install
# צור .env.local עם DATABASE_URL (Neon) ו-AUTH_SECRET  (ראה DEPLOYMENT.md)
npm run db:migrate     # סכימה + קבוצת ברירת מחדל + משתמש מנהל (מדפיס סיסמה)
npm run dev            # http://localhost:3000
```

* פריסה מלאה, ענן, ואבטחה: **[DEPLOYMENT.md](DEPLOYMENT.md)**
* התקנת הטלוויזיות: **[kiosk/README.md](kiosk/README.md)**

## איך זה עובד

1. המנהל יוצר קבוצה ועורך את הלוח שלה מהנייד → נשמר ב־Neon.
2. הטלוויזיה פותחת את `/display`, מקבלת מזהה, ומציגה QR.
3. המנהל סורק את ה־QR ומשייך את המסך לקבוצה.
4. המסך מציג את לוח הקבוצה, מתעדכן אוטומטית (polling + refetch), ושומר הכל
   במטמון (localStorage + IndexedDB + Service Worker) כדי לעבוד גם ללא רשת.

## מבנה

```
src/app/
  display/         # הלוח (מנוע התצוגה + מוזיקה + שיוך QR)
  admin/           # ממשק הניהול (RTL, מובייל)
  api/             # groups, screens, media, auth, display/content, zmanim, halacha…
src/lib/           # db (pg), auth (jose+bcrypt), types, display-payload, screen
db/schema.sql      # סכימת Neon Postgres
public/welcome1|2/ # העיצוב המקורי של הלוח (HTML/CSS/JS/פונטים) — מנוע board-data.js
kiosk/             # סקריפטי Windows kiosk + מדריך
scripts/migrate.mjs
```
